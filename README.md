# AxionOS coral kernel

Migration source: https://github.com/its-hecker/evox-coral-kernel

Google floral 4.14 kernel with the existing KernelSU Next git submodule preserved. The source snapshot is mirrored to the separate `cnb-android17-prep` branch by GitHub Actions.

Do not replace this with a mismatched kernel prebuilt or flash boot.img alone: vendor kernel modules must match the compiled kernel. Pending Axion Android 17 build and on-device validation.
